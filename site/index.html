dus

Voyez en un coup d'œil quelles entrées d'un dossier prennent le plus de place.

Installation

Aucune dépendance, seulement Node.js 18 ou plus.

git clone <url-du-depot> dus
cd dus

Utilisation

node bin/dus.js [dir] [-n 10] [--json]
  • dir : le dossier à analyser (par défaut le dossier courant)
  • -n : nombre d'entrées affichées
  • --json : sortie lisible par une machine

Tests

npm test
